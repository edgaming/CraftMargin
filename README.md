# Craft Margin

A World of Warcraft addon for WoW Forever that shows which of your recipes make the most money.

- One tab per crafting profession, recipes sorted by profit.
- Prices come from Auctionator or TradeSkillMaster, whichever you have (pick with the cogwheel if you have both). Materials use the cheaper of the AH price and the vendor price.
- Shift-click a recipe to shop for its materials: Auctionator searches for you; with TSM you get a search string to paste.
- Hover a profit to see the math: sale price, yield, 5% AH cut, materials.
- It never posts, buys or whispers anything.

## Install

Unzip so the folder sits directly in `Interface\AddOns\CraftMargin\` (the `.toc` must be inside that folder, not one level deeper). Requires [Auctionator](https://www.curseforge.com/wow/addons/auctionator) or [TradeSkillMaster](https://www.curseforge.com/wow/addons/tradeskill-master) for prices.

## Quick start

1. Scan the auction house with Auctionator.
2. Open each profession window once. Craft Margin reads your learned recipes and remembers them.
3. Type `/margin`.

## Commands

- `/margin` opens or closes the window.
- `/margin debug` prints what the addon knows, for bug reports.

## Known limitations

- Learned recipes for the current character only.
- No sales volume: a recipe can show a big margin and still sell slowly.
- Crafted materials are costed at their AH price, not at the cost of crafting them yourself.

## Development

- Layout: `Core/` (namespace, events, helpers, API layer), `Domain/` (prices, recipes, costing, ranking), `UI/`, `Commands.lua`.
- Tests: `pip install lupa`, then `python tests/run.py`.
- Package locally: `python tools/package.py` writes `dist/CraftMargin-<version>.zip`.
- Release: bump `VERSION` and push to `main`. The Release workflow runs the tests, tags `v<version>` and publishes a GitHub release with the BigWigs packager. WowUp picks it up via Install from URL.
- Vendor prices: `Domain/VendorData.lua` is generated by `tools/gen_vendor_prices.py` from the [CMaNGOS Classic database](https://github.com/cmangos/classic-db) (item IDs and base buy prices only).
